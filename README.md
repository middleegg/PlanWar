#PlanWar 
An industry-oriented module will feature a lengthy storyline and campaign, as well as a wealth of new content! It primarily utilizes Json (possibly incorporating some Toml), contains JavaScript content, and some libraries involve Kotlin and Java.

Промышленный мод с длинными сюжетами и кампаниями, а также множеством нового контента! Основан на Json (возможно, с некоторым TOML), содержит JS, некоторые библиотеки используют Kotlin и Java.
