# Plan War 
A Mindustry mod contains a lengthy storyline and campaign, as well as a wealth of new content! 
</br>It primarily utilizes `JSON` (possibly incorporating some `TOML`), contains JavaScript content, and some libraries involve `Kotlin` and `Java`.

Промышленный мод с длинными сюжетами и кампаниями, а также множеством нового контента! Основан на JSON (возможно, с некоторым TOML), содержит JS, некоторые библиотеки используют Kotlin и Java.
